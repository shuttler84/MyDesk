# MyDesk 使用说明

## 1. 安装与启动

- **安装版**：运行 `MyDesk-1.0.0-Setup.exe`，按向导完成安装（可自定义目录），桌面/开始菜单自动创建快捷方式。
- **便携版**：`MyDesk-1.0.0-Portable.exe` 免安装，直接运行（数据仍保存在 `%APPDATA%/mydesk`）。
- MyDesk 支持单实例：重复启动会聚焦已开窗口。

## 2. 界面

左侧固定导航栏切换 8 个模块；顶部工具栏提供全局搜索、快速添加任务、最近活动通知、主题切换与本地数据状态指示。

## 3. 主题与动画

- 顶栏调色板图标或 Settings 页可切换 **Mint / Lavender / Cream / Midnight / Glass** 五种主题，选择自动保存。
- Glass 主题使用透明玻璃效果，所有文字保持可读。
- Settings → Animation：Full（全部动画）/ Reduced（减少动画）/ Off（关闭动画）。

## 4. Tasks 任务

- 视图：**Today**（未完成且截止日 ≤ 今天，无截止日期的任务也算今日；昨天的未完成任务自动延续，不会重复生成也不会丢失）、**Upcoming**、**Completed**、**All**。
- 新建任务：标题、优先级（高/中/低）、截止日期/时间、备注、重要置顶。
- 拖拽排序自动保存；重要事项固定在列表顶部。
- 点击圆圈完成任务（带完成动画），再次点击可撤销。

## 5. Collections 收藏

- 新增收藏：粘贴 URL 失焦后自动抓取标题/描述/图标/预览图（失败可全部手动填写），自动检测重复收藏，自动猜测类型（GitHub/Bilibili/YouTube 等）。
- 支持卡片/列表两种视图、类型筛选、研究状态筛选（未研究/研究中/已完成，点标签轮换）、多标签筛选、关键词搜索。
- 每张卡片：浏览器打开、复制链接、编辑、删除。

## 6. Private Vault 保险箱

- 首次进入设置独立主密码（≥8 位）。**主密码丢失无法恢复加密内容，请务必牢记。**
- 每次进入需解锁；闲置 N 分钟（默认 10，可设置）或手动点击 Lock 即锁定。
- 分类：Website Accounts / Developer Accounts / API Keys / Servers / Databases / Private Notes。
- 密码默认隐藏：眼睛图标临时显示；复制图标复制密钥，剪贴板将在设定秒数（默认 30）后自动清空。
- Settings 区可更改主密码（全部数据重加密）。

## 7. File Index 文件索引

- 点击 Index file 选择文件，或手动输入完整路径（自动读取文件名/类型/大小）。
- 每条记录可：检查路径有效性（失效自动标记 missing）、打开文件、打开所在目录、复制路径、编辑版本号/备注/标签。
- MyDesk 只记录位置，绝不移动、复制或删除你的文件。

## 8. Notes 笔记

- Markdown 编辑（支持代码块、表格、引用等 GFM 语法），Edit/Preview 切换。
- 附件：Attach 按钮添加图片等文件（≤20MB），在正文中以 `![名称](attachment:ID)` 引用，预览时显示；可另存副本或删除。
- 分类、标签、搜索、标题均支持；自动保存创建/修改时间。

## 9. Timeline 时间轴

- 四类每日统计（任务完成/收藏/笔记/文件索引）+ 最近活动时间线；支持起止日期筛选。

## 10. 备份与恢复（重要）

- **导出**：Settings → Export backup，生成 `.mydeskpack` 完整备份（数据库快照 + 附件 + 校验值）。保险箱数据保持加密——没有主密码谁也读不出内容。
- **恢复**：Restore backup 选择 `.mydeskpack`，软件会先验证完整性并预览数据量，确认后执行**完整恢复**（覆盖当前数据；恢复前自动再做一次安全快照，失败自动回滚，原数据无损）。
- **建议**：定期导出备份到另一块磁盘或网盘（文件本身是加密保险箱 + 普通数据，注意普通数据部分为明文 SQLite，请自行评估存放位置）。
- 普通导出：JSON（全量）、CSV（任务/收藏/文件索引）、Markdown（笔记），均不含保险箱内容。

## 11. 数据位置与卸载

- 数据目录：`%APPDATA%/mydesk`（Settings 页显示实际路径）。
- 卸载软件不会删除该目录；如需彻底清除请手动删除（注意先导出备份）。

## 12. 阶段二新功能（1.1.0）

### 全局搜索
- 顶栏搜索框覆盖：任务名称/备注、收藏名称/URL/描述/个人备注/标签、文件名称/路径/备注、笔记标题/正文。
- **Ctrl+K** 快捷呼出；实时搜索、按模块筛选、关键词高亮；自动记住最近 10 条搜索历史。
- 保险箱内容永远不出现在搜索结果中。

### 全局快速添加（Ctrl+Shift+Space）
- 任何时刻（包括窗口最小化到托盘时）按 **Ctrl+Shift+Space** 呼出快速添加条。
- 自动识别输入：网址 → 网站收藏；GitHub 仓库链接 → GitHub 收藏；本机文件路径 → 文件索引；普通文本 → 任务。
- 识别不准时可手动点选类型；Enter 保存、Esc 关闭、点击窗口外自动收起。
- 全局快捷键被占用时会通过通知中心提示。

### 系统托盘与提醒
- 关闭主窗口时可选择"最小化到托盘"或"退出"，可记住选择（设置中可改）。
- 托盘左键显示主窗口；右键菜单：显示主窗口 / 全局快速添加 / 立即备份 / 退出。
- 任务到期提醒：新建/编辑任务时可设置"到期时 / 提前 5 分钟～1 天"，默认策略在设置中配置；同一任务只提醒一次。
- 勿扰时段（设置 → 提醒与托盘）内不弹系统通知，只进入通知中心。
- 可开启"开机自动启动"。
- 注意：软件完全退出后不会有任何后台提醒（托盘常驻 = 后台运行，可正常提醒）。

### 通知中心
- 顶栏铃铛汇聚全部通知（任务提醒、备份结果、错误提示），未读角标计数，可一键清空。

### 收藏增强
- 粘贴 GitHub 仓库链接时自动获取仓库名与简介。
- 勾选多条收藏后可批量修改标签（追加/替换）、批量删除、导出选中为 CSV。

### 文件索引增强
- "批量添加"一次索引多个文件；"批量检查"带进度条。
- "仅看失效"集中展示失效路径；"按目录分组"归类显示；顶部显示总大小统计。
- 支持勾选后"导出选中"。

### 备份中心（设置页）
- 自动备份：每天/每周静默执行，保留份数可设，失败通过通知中心提醒。
- 备份历史：每份备份展示大小、时间、软件版本、结构版本、数据量、是否含加密保险箱、完整性结果。
- 支持一键完整性检查、从历史恢复（恢复前自动安全快照）、删除、打开备份文件夹。

## 13. 阶段三新功能（1.2.0）

### 时间轴升级
- **年度活动热力图**：GitHub Contributions 风格，支持年份切换、按活动类型筛选（任务完成/收藏/笔记/文件索引/全部）；点击任意日期查看当天各项明细。
- 每月任务完成柱状图、收藏类型分布、标签使用 Top 30。
- 所有统计来自真实数据库；没有数据的日期显示为空。

### 高级收藏管理
- **自定义分组**：右上"分组管理"新建分组；勾选收藏后用批量工具条"加入分组"；分组可重命名、删除（组内收藏自动变为未分组）。
- **高级排序**：最新创建/最早创建/最近修改/名称/重要程度。
- **标签组合**：选多个标签后可在"全部包含（AND）/任一包含（OR）"间切换。
- **统计面板**：类型分布、重复 URL 检测、同域名相似收藏提醒。
- **修改历史**：每条收藏的"修改历史"按钮可查看每次修改前的快照。

### 浏览器扩展（Chrome/Edge 等 Chromium 浏览器）
- 设置 → 浏览器扩展：启用本地服务，复制令牌。
- 浏览器 → 扩展管理 → 开发者模式 → "加载已解压的扩展程序" → 选择 MyDesk 安装目录下 `browser-extension` 文件夹（便携版在解压目录内）。
- 扩展选项页粘贴令牌保存；之后在任意网页点扩展图标即可一键收藏（含分组/标签/备注），数据只发到本机。
- 令牌可随时重置；本地服务仅监听 127.0.0.1，不暴露到网络。

### 高级文件索引
- **目录扫描**：选择目录、文件类型与深度 → 扫描 → 预览 → 确认后加入索引；可随时取消。MyDesk 只读取元信息，绝不动文件。
- **导入 CSV**：兼容第一阶段导出的 CSV 格式，自动跳过重复路径。
- **统计面板**：类型分布、总大小、失效数、近 7 天新增、重复路径。
- **失效清理建议**：一键列出失效路径，确认后从索引移除（不触碰磁盘文件）。

### 数据管理（独立页面）
- 侧边栏新增"数据管理"：数据库完整性检查（integrity + 外键）、Schema Migration 历史记录、备份/恢复/自动备份/备份历史集中管理、跨设备迁移分步指引。

## 14. 常见问题

- **忘记保险箱主密码？** 无法恢复，这是设计保证（无后门）。只能删除 vault 数据重新开始。
- **收藏抓取不到标题？** 目标网站可能超时/反爬，手动填写即可。
- **文件索引显示 missing？** 文件被移动/删除了；更新路径或移除条目。
