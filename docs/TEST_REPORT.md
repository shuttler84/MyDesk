## 3. E2E 走查中发现并修复的问题

| # | 问题 | 严重性 | 修复 |
| --- | --- | --- | --- |
| 1 | 5 个辅助查询通道（收藏标签/笔记分类/文件类型等）未加入 preload 白名单，页面弹出 "Unknown channel" 错误提示 | 高（功能受损） | 通道加入 `src/shared/ipc.ts` 统一白名单，重新验证通过 |
| 2 | Electron 45 将 `clipboard.readText()` 改为异步 API，与适配层签名不符 | 中（编译期发现） | `PlatformAdapter` 接口与剪贴板清理逻辑改为异步 |
| 3 | 备份恢复时解压路径少一级 `data/` 目录，node:sqlite 静默创建空库导致"恢复后无表" | 高（测试发现） | 修正路径 + 增加空库防御校验（user_version=0 即拒绝） |
| 4 | 迁移记录 INSERT 误用 `exec`（无法绑定参数） | 高（测试发现） | 改为 `prepare().run()` |

## 4. 视觉验收结论

40 张真实运行截图（5 主题 × 8 页面）人工逐一检查：

- 五种主题均正确渲染，色彩与主题定位一致；Midnight 深色下正文/标签对比度良好；Glass 主题半透明卡片 + 背景模糊且文字清晰。
- 布局无重叠/溢出/截断；侧边栏、顶栏、卡片、弹窗、空状态风格统一；空状态提供引导操作。
- 未发现 JS 白屏、空白内容区、渲染崩溃。
- 截图存档：`build/ui-shots/`（走查工具 `src/main/uiTour.ts`，仅设 `MYDESK_UI_TOUR` 环境变量时启用，不影响正常使用）。
