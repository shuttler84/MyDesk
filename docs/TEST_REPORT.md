## 3. E2E 与走查中发现并修复的问题

| # | 问题 | 修复 |
| --- | --- | --- |
| 1 | **提醒调度器把数据库 snake_case 原始行直接传入 findDueCandidates**，读取 camelCase 的 reminderMinutes 恒为 undefined，提醒永远不触发 | 统一用 rowToTask 转换后再计算（E2E 发现） |
| 2 | 快速添加识别器引入 Node fs，会导致渲染进程构建失败 | 改为纯启发式识别，保存时再校验 |
| 3 | Electron MessageBoxOptions 无 checkboxes 字段 | 关窗询问改为三按钮（最小化 / 最小化并记住 / 退出） |
| 4 | backupService 追加代码重复导入 fs 符号 | 合并导入 |
| 5 | 旧测试写死 Schema Version 1 | 改为引用 LATEST_SCHEMA_VERSION 常量 |
