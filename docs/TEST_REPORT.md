## 5. 已知边界

- 浏览器扩展需要手动"加载已解压的扩展程序"安装（未上架商店）；仅支持 Chromium 内核。
- 目录扫描为同步执行（有数量上限 2000 与取消标志），万级文件目录建议缩小范围。
- "合并导入"仍未提供（保持第一阶段的如实原则，仅完整恢复）。
- Android 端未开发（按任务书仅完成架构检查与设计文档 docs/ANDROID_ROADMAP.md）。
- Git 由项目所有者手动提交（用户已确认）。
